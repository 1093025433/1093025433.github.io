🛠️二、环境准备

◆ Hexo的运行依赖 Node.js 和 Git，先安装它们。

🔺Node.js：

  • 是什么：让 JavaScript 能够脱离浏览器，在你的电脑或服务器上直接运行的一套“运行环境”。

    （JavaScript（简称 JS）是一种编程语言，最初主要用于让网页“动起来”。）

    在这里 需要Node.js 在执行 Hexo 的 JavaScript 代码

  • 注意：版本需 ≥ 10.13，建议使用 12.0 及以上。

🔺 Git：

  • 是什么：是一个分布式版本控制系统，用来记录文件的变化历史，方便你回退、对比和多人协作。

    但是Git 和我们常听到过的 GitHub 不是一回事，Git 是工具，而GitHub 是基于 Git 的代码托管平台。

  • 作用：通过 Git 推送到 GitHub 仓库发布博客。

👀 四、本地预览博客

到这一步说明你已经完成得差不多了。

为了确认博客能正常运行，建议先进行本地预览。

1. 生成静态文件 hexo generate
2. 启动本地服务 hexo server
然后浏览器打开 http://localhost:4000/（ctrl+右击）

[!NOTE]

常用命令及缩写也可以记一下

hexo generate ——生成静态文件 hexo g

hexo server —— 启动本地服务 hexo s

基础目录结构

  • _config.yml：Hexo 全局配置文件
  • source/_posts/：文章存放目录
  • themes/：主题目录
  • public/：生成后的静态文件目录
  • scaffolds/：文章模板目录

最常接触的通常是：

  1. 写文章：source/_posts/
  2. 改站点信息：_config.yml
