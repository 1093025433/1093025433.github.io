CMD小白教程

发表于2026-10-11|更新于2026-10-11
|浏览量:

介绍：CMD（命令提示符）是Windows 系统内置的命令行工具

打开方式：Win + R → 输入 cmd → 回车

⭐ 路径的介绍

路径是指文件在文件系统中的位置，路径通常由以下几部分组成： ◆盘符（如C:、D:等文件所在的磁盘分区） ◆目录：也叫做文件夹（存放文件的地方） ◆文件名（即文件的名称）

① 绝对路径 —— 从盘符开始

特点：完整、明确，在任何位置都能用

其他打开方式

在相应文件位置，右击再按T也能打开CMD)。

②相对路径 —— 从当前位置开始

假设在 C:\Users\Tom

[!NOTE]

如果路径或文件名含空格，要用双引号包起来

⭐ 最常用的Windows CMD命令速查表

命令 作用 示例
dir 列出当前目录内容 dir
cd 切换目录 cd D:\projects
cd .. 返回上一级目录 cd ..
mkdir 创建文件夹 mkdir test
copy 复制文件 copy a.txt D:\backup\
move 移动或重命名 move a.txt b.txt
del 删除文件 del a.txt
type 查看文本文件内容 type readme.txt
ipconfig 查看 IP 等网络配置 ipconfig
ping 测试网络连通性 ping www.baidu.co
cls 清屏 cls
exit 退出 CMD exit

[!TIP]

help 命令：查看帮助

  1. help 加命令名：显示它的帮助说明。 help/?
  2. 任意命令后面加 /?：显示它的帮助说明。 命令 /?

⭐ 实用小技巧

技巧 做法
自动补全 按 Tab
翻历史命令 按 ↑ / ↓，或 F7
清屏 cls
中途取消命令 按 Ctrl + C
暂停输出 按 Ctrl + S，再按任意键继续
快速打开当前目录的 CMD 文件资源管理器地址栏输入 cmd 回车
复制窗口内容 标题栏右键 → 编辑 → 全选 → 回车

⭐复制粘贴

（没错，这也教）

  • 复制：标题栏右键 → 编辑 → 标记 → 选中内容 → 回车，或直接 Ctrl + c
  • 粘贴：标题栏右键 → 编辑 → 粘贴，或直接 Ctrl + V
  • 全选：Ctrl + A

⭐一次执行多条命令

符号 含义 示例
&& 前一条成功才执行后一条 mkdir test && cd test
& 不管成功与否都执行 dir & cls
` ` 管道，把前一条结果传给后一条
◆例子

⭐常见报错

提示 意思
不是内部或外部命令 命令拼错了，或该程序没装/不在 PATH 里
系统找不到指定的路径 路径写错，或目录不存在
拒绝访问 权限不够，试试管理员身份
文件名、目录名或卷标语法不正确 路径格式错了（比如少了冒号、斜杠反了）
